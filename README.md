# FixTok

FixTok is an unofficial TikTok client for Android TV, built around a single full-screen WebView.

## Features

- 🖥️ Desktop version of TikTok
- 🌐 Single full-screen WebView
- 🖱️ Virtual mouse controlled by the TV remote
- 🎮 D-pad navigation
- ✅ OK / Enter — click
- ◀️ Back — browser history / exit
- 🍪 Cookie and session persistence
- 🎬 HTML5 fullscreen video support
- ⚡ Hardware acceleration
- 🚀 Splash screen
- 👤 by Manas

## Remote Control

| Remote Button | Action |
|---|---|
| ↑ | Move cursor up |
| ↓ | Move cursor down |
| ← | Move cursor left |
| → | Move cursor right |
| OK | Click |
| Back | Go back |
